The Last Transmission

Asterion Technologies has reported a suspected data breach. One of its internal workstations communicated with an unfamiliar external server shortly before confidential information disappeared from the organisation's systems.

The security team recovered a packet capture from the affected network segment. It contains DNS lookups, HTTP requests and an unusual file transfer. Individually these events look ordinary — together they may reveal what happened.
