Phantom Protocol

A decommissioned license client from the Phantom Protocol pilot was recovered from an intercept. Its companion data file survived, but the accepted access token is not recorded anywhere.

Testing a candidate token

  1. Extract unzip phantom-protocol-package.zip
  2. Enter the directory cd phantom-protocol
  3. Make it executable chmod +x phantom-client
  4. Check a candidate ./phantom-client --verify 'CANDIDATE'

The client loads protocol.dat from its own directory. Running it without arguments prints the usage summary.

Analyst notes

The intercept contains the client and its data file only. No source, no build scripts and no documentation were recovered. The client reports only whether a candidate is accepted; it never discloses the stored token.

The transformation applied to protocol data is reversible by design. Treat the executable and protocol.dat as a single artifact.
