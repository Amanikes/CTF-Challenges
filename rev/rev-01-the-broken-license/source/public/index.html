Running the utility

  1. Extract unzip northstar-license-package.zip
  2. Enter the directory cd northstar-license-package
  3. Make it executable chmod +x northstar-license
  4. Run and enter a license key ./northstar-license

license.dat must stay in the same directory as the executable. The utility reads it at start-up and reports a missing data file otherwise.

About this build

The license checking routine was written by a contractor who has since left the company. Source code, build scripts and the original signing documentation were not retained. Operations can confirm that a correctly licensed installation accepts its key, but the accepted value itself is not recorded anywhere in this archive.
